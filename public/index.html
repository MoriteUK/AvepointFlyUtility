AOS Session

The Connections screen uses a saved Playwright browser session to authenticate with the AvePoint Online Services portal. Authenticate on your local machine, then upload the resulting auth/storageState.json.

Loading...
How to generate a session file on your local machine:
  1. Open a terminal in the Scripts/Avepoint/FLY folder.
  2. Run: npm run login
  3. Complete Microsoft SSO + MFA in the Chrome window that opens.
  4. Close Chrome (or wait — the script detects the post-login page automatically).
  5. Upload the generated auth/storageState.json using the form above.
